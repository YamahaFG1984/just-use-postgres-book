SQL 练习场

这一页在你的浏览器里运行一个真正的 Postgres（PGlite，Postgres 编译成的 WebAssembly 版本），并预先装好了一家小咖啡店的示例数据。 写 SQL、按 Ctrl + Enter（Mac 上是 ⌘ + Enter）就能看到结果。改坏了也没关系，点“重置数据库”就回到初始状态。

ⓘ 和书里的环境有什么不同
  • 这里是 Postgres 18，数据只在内存里，刷新页面就会恢复原样（你写的 SQL 会保存在本浏览器里）。
  • 只有一个会话、一个数据库：\c、\d 这类 psql 命令用不了，会被跳过；并发、锁的实验要回到 Docker 里做。
  • pgvector、PostGIS、TimescaleDB 等扩展没有加载；第 8～10 章的内容请用 Docker 环境。
  • 首次运行需要下载约 10 MB 文件（来自 cdn.jsdelivr.net），之后浏览器会缓存。

-- 示例数据：一家小咖啡店
CREATE TABLE customers (
  id serial PRIMARY KEY,
  name text NOT NULL,
  city text NOT NULL,
  joined_at date NOT NULL
);
CREATE TABLE products (
  id serial PRIMARY KEY,
  name text NOT NULL,
  category text NOT NULL,
  price numeric(8,2) NOT NULL CHECK (price > 0),
  stock int NOT NULL DEFAULT 0,
  attrs jsonb NOT NULL DEFAULT '{}',
  description text
);
CREATE TABLE orders (
  id serial PRIMARY KEY,
  customer_id int NOT NULL REFERENCES customers,
  ordered_at timestamptz NOT NULL,
  status text NOT NULL CHECK (status IN ('pending', 'paid', 'shipped', 'cancelled'))
);
CREATE TABLE order_items (
  order_id int REFERENCES orders,
  product_id int REFERENCES products,
  quantity int NOT NULL CHECK (quantity > 0),
  price numeric(8,2) NOT NULL,
  PRIMARY KEY (order_id, product_id)
);

INSERT INTO orders (customer_id, ordered_at, status)
SELECT (ARRAY[1,3,2,5,1,4,6,2,8,3,1,7,2,5,3,1,6,4,2,8,1,3,5,2,7,1,4,3,6,2,1,5,8,3,2,4,1,6,7,3])[g],
       timestamptz '2025-01-01 09:00+00' + (g * 4 || ' days')::interval + (g % 9 || ' hours')::interval,
       (ARRAY['paid', 'shipped', 'shipped', 'paid', 'pending', 'cancelled', 'shipped'])[1 + g % 7]
FROM generate_series(1, 40) AS g;

INSERT INTO order_items (order_id, product_id, quantity, price)
SELECT o.id, p.id, 1 + get_byte(decode(md5(o.id || '+' || p.id), 'hex'), 1) % 3, p.price
FROM orders o
JOIN products p ON get_byte(decode(md5(o.id || '-' || p.id), 'hex'), 0) % 10 < 2
                OR p.id = 1 + o.id % 10;   -- 保证每个订单至少有一件商品

小提示

想做的事psql 里的写法这里用 SQL 代替
列出所有表\dtSELECT table_name FROM information_schema.tables WHERE table_schema = 'public';
看表结构\d productsSELECT column_name, data_type, is_nullable FROM information_schema.columns WHERE table_name = 'products';
看索引\diSELECT indexname, indexdef FROM pg_indexes WHERE schemaname = 'public';
看扩展\dxSELECT * FROM pg_available_extensions ORDER BY name;
  • 一次可以写多条语句，用分号隔开；和 psql 一样，某一条出错，后面的照常执行。
  • 事务里出错后，练习场会自动 ROLLBACK，免得后面的语句全部报 “current transaction is aborted”。
  • 想练第 2～4 章的建表、约束、索引？直接在这里 CREATE TABLE 自己的表就行。
  • 本站的专题 2 里，代码块右上角也有“运行”按钮。
